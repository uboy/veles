# Veles

Knowledge Core: личная и корпоративная база знаний с RAG и верифицируемыми цитатами.
Личный офлайн-профиль (Windows/macOS/Linux, один процесс) — MVP; корпоративный контур —
задел на старте (интерфейсы), build-out позже.

- Архитектурный стандарт: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) (v3.0)
- Базис кода перенесён из предыдущего приватного проекта (порт-карта в истории).
- Каталог корпуса: `~/proj/knowledge-sources/` (заполняется по allowlist-конвейеру, §7 стандарта)
- Трекер-карточка эпика: ai-tracker `work/corp-ai-kb/task-corp-ai-kb-architecture-and-prototype.md`

## Статусы норм (K18)

При индексации узлам, чей текст содержит «утратил силу» / «не подлежит
применению», в `node_meta` пишется `lost_force: true`. Узел не скрывается и
ранжирование не меняется (research: показывать с явной меткой), но:

- цитаты в JSON (`/v1/knowledge/query`, `veles`-блок chat/completions) несут
  `lost_force: true` - старые клиенты поле игнорируют;
- в рендерах перед такой цитатой ставится плашка «⚠ Норма утратила силу»
  (чат-рендер фасада, Telegram-мост, CLI `veles ask`).

Ограничение (честно): метка детектируется **по тексту узла**. Официальный
статус акта на уровне документа (источник - pravo.gov.ru) - отдельная будущая
фаза. Прод-индекс стенд пересобран 2026-09-30 с метками (1506 узлов); старый
индекс без поля читается как `lost_force: false` без пересборки и ошибок.

Статус: рабочий срез в проде (стенд, рунбук - docs/DEPLOY-стенд.md); развёртывание
в новом контуре - deploy/kit/README.md.
