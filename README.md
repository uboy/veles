## Статусы норм (K18)

При индексации узлам, чей текст содержит «утратил силу» / «не подлежит
применению», в `node_meta` пишется `lost_force: true`. Узел не скрывается и
ранжирование не меняется (research: показывать с явной меткой), но:

- цитаты в JSON (`/v1/knowledge/query`, `veles`-блок chat/completions) несут
  `lost_force: true` - старые клиенты поле игнорируют;
- в рендерах перед такой цитатой ставится плашка «⚠ Норма утратила силу»
  (чат-рендер фасада, Telegram-мост, CLI `veles ask`).

Ограничение (честно): метка детектируется **по тексту узла**. Официальный
статус акта на уровне документа (источник - pravo.gov.ru) - отдельная будущая
фаза. Прод-индекс получит метки при следующей плановой пересборке
(`python -m veles index`); старый индекс без поля читается как `lost_force: false`
без пересборки и ошибок.

Статус: scaffold. Следующий шаг — план фаз и вертикальный срез (план в трекере).
