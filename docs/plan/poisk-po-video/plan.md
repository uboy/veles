# План: поиск по видео (расшифровка с таймкодами)

> Эпик `poisk-po-video`. Заказ владельца 2026-10-11 («реализуй поиск по видео»,
> го на дизайн: расшифровка речи в общий гибридный индекс с цитатами по
> таймкодам; кадры - активы, CLIP-индекс кадров - после включения канала
> изображений). Бриф: `docs/plan/briefs/2026-10-11-poisk-po-video.md`.

## Фаза 1. Схема и таймкоды в цитатах

Цель: таймкод - полноценный локатор наравне со строками/страницами.
Файлы: `veles/canonical/model.py` (Provenance += t_start/t_end, Optional[float],
секунды), `veles/retrieval/retriever.py` (Citation += t_start/t_end из
node_meta.provenance; human() печатает «00:12:34»), `veles/api/app.py`
(цитата в /v1/knowledge/query несёт t_start/t_end; рендер chat/completions
печатает таймкод перед текстом цитаты).
Проверка: юнит-тесты - roundtrip Provenance с t_start/t_end; Citation.human()
для видео-узла; цитата query-ответа содержит t_start/t_end; у старых документов
поля None и рендер не меняется (обратно-совместимость).

## Фаза 2. Парсер видео и очередь

Цель: видео-файл ингестится как документ с узлами-сегментами речи.
Файлы: `veles/ingest/voxfusion.py` (клиент: POST /v1/transcribe
include_segments=true, поллинг GET /v1/jobs/{id}; env VOXFUSION_API_URL /
VOXFUSION_API_TOKEN - те же имена, что у Telegram-моста),
`veles/ingest/video.py` (адаптер video:0.1: ffmpeg -> аудио wav 16k mono +
ключевые кадры в assets; сегменты сливаются в узлы ~700-1200 знаков с
t_start/t_end; нет токена - понятный отказ, нет речи - документ с заглушкой),
`veles/ingest/queue.py` (расширения mp4/mkv/mov/webm/m4v/avi, route).
Проверка: юнит-тесты с фейковым клиентом VoxFusion (без сети) и
ffmpeg-фикстурой (skipif ffmpeg недоступен): узлы несут таймкоды, кадры в
assets, отказ без токена человекочитаем, txt/md/pdf не сломаны.

## Фаза 3. Eval на реальном видео

Цель: доказать сквозной поиск с таймкодом на настоящей транскрибации.
Файлы: `evals/results/2026-10-11-video-search.md` (+ скрипт и фикс пару в
каталоге evals). Метод: PowerShell SAPI TTS синтезирует wav с тремя
маркерными фразами в известные секунды; ffmpeg собирает mp4 (видеодорожка
testsrc2 + аудио); ингест через живой фасад на локальной машине; вопрос по
маркеру -> топ-цитата - нужный узел, таймкод в допуске окна сегмента.
Транскрибация - настоящий VoxFusion (bm1:8500), не мок.
Проверка: hit по всем трём маркерам, таймкод в границах сегмента; отрицательный
кейс - вопрос без опоры даёт отказ (гейт ответности не сломан).
