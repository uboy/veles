# veles ask - вопрос к базе знаний

## Когда применять

- вопрос по содержимому корпоративного корпуса: лекции, нормативка, регламенты;
- перед записью факта в задачу или заметку - подтвердить источником;
- пользователь просит «найди в базе», «что в курсе про ...».

## Вызов

    veles ask "<вопрос одним предложением>"

`--top-k N` - сколько фрагментов доставать (по умолчанию 8). Индекс должен
быть собран (`veles index`); без него команда ответит «индекс не собран -
сначала index».

## Как читать ответ

1. Строка `решение: ANSWER (доверие N; ...)` - база нашла доказательство.
   `NOT ENOUGH EVIDENCE` - доказательств в корпусе нет: так и ответь,
   ничего не сочиняй.
2. Блок `ответ (текст узла, N знаков)` - дословный фрагмент из источника.
3. Блок `цитаты:` - источники (файл, путь заголовков). В ответе и в карточках
   ссылайся только на эти цитаты; утверждение без цитаты помечай как
   не подтверждённое.
4. Блок `diagnostics:` - служебные ранги поиска, в ответ его не включай.
