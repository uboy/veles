# tracker-task - задача в трекер veles

## Куда пишем

Задачи: `<chat_id>/task/task-ГГГГММДД-NN-slug.md`. chat_id - номер чата
владельца в Telegram, он же имя существующего каталога в корне (для нового
пользователя создай каталог с его chat_id). NN - следующий свободный порядковый
номер за сегодня в этом каталоге (посмотри существующие файлы). Заметки -
соседний каталог `note/`, формат тот же.

## Формат карточки

YAML-шапка + тело (полные правила - AGENTS.md в корне каталога):

    ---
    id: task-20260929-03-podgotovit-otchet
    title: "Подготовить отчёт по регламенту"
    status: todo
    created: 2026-09-29T18:30:00
    source: manual
    due: 2026-10-03
    ---

    Подготовить отчёт по регламенту due:2026-10-03 и показать на планёрке.

- дедлайн: тег `due:ГГГГ-ММ-ДД` в тексте, строка `due:` в шапке повторяет его
  (по шапке работает напоминалка и веб);
- slug - только латиница и цифры, кириллица - в title и теле;
- статус меняется правкой `status:`, значения - todo и done, других нет.

## Как создать

- Telegram: `/task текст` - бот сам построит карточку и закоммитит; текст
  длиннее 1500 знаков бот считает транскрипцией и извлечёт из него список
  задач;
- напрямую файлом: создай карточку по формату выше и закоммить
  (`git add -A && git commit -m "task: суть"`). Ошибка index.lock - в этот
  момент писал бот; повтори команду через несколько секунд.

## Закрытие

`status: done` правкой строки в шапке (или `/done часть-id` в Telegram).
done ставится только после фактической проверки результата - «готово =
проверено»; что не проверено, оставайся в todo и опиши причину в теле.
