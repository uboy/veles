# Демо-контент кита (демо в один клик)

Состав каталога:

- `documents/` - 5 синтетических корпоративных документов (фикшн-компания
  ООО «Ромашка»: отпуска, командировки, ИТ-доступы, закупки, FAQ поддержки).
  Реальных данных нет; все телефоны/почты - внутренние вымышленные
  (домен romashka.example).
- `index/` - готовый мини-индекс по этим документам (модель эмбеддингов
  intfloat/multilingual-e5-small, та же, что в проде; backend numpy).
  Собирается `bash build-demo-index.sh` (нужен venv с veles[st]).
- `canonical/` - канон тех же документов (нужен фасаду: страница источника
  по ссылке из цитаты, `veles status`).
- `questions.txt` - 5 проверенных на этом индексе демо-вопросов.

`install.sh --demo` копирует `index/` -> `<данные>/index`, `canonical/` ->
`<данные>/canonical`, `documents/` -> `<каталог установки>/corpus/demo`
и печатает вопросы в финале установки.

Индекс несёт вектора документов, но для эмбеддинга ВОПРОСА модель e5-small
нужна и на машине демо: при первом `veles ask` она скачается с HuggingFace
(~130 МБ, кешируется в ~/.cache/huggingface). `install.sh --demo` прогревает
модель сразу после установки, чтобы демо не упало на первом вопросе.
